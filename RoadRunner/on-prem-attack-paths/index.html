Sample path finding · RR-F-0142

Service account creates path from workstation admin to Tier 0

HIGH
AffectedCORP\svc-build, Workstation Admins, ENG-WS-044, Domain Admins
EvidenceCollector graph shows memberOf, localAdmin, and activeSession edges forming a route to Tier 0.
RiskAn attacker controlling the service account can move through a managed workstation into a privileged session.
Recommended actionRemove the account from broad workstation administration or isolate admin sessions from exposed endpoints.
ValidationNext collector run must show no route from CORP\svc-build to Tier 0.
Closure rule Manual status cannot close this finding. Evidence from the next run must satisfy the validation condition.
Collector model

Read-only, scoped, and deployable by normal IT operations.

The collector should be explainable to an AD owner before it ever runs.

Permissions

Scoped read access

Enough to enumerate directory objects, group membership, ACLs, delegation, and computer metadata. Nothing more.

Collected

Topology, not secrets

Users, groups, computers, memberships, privileged relationships, ACL edges, delegation indicators, source timestamps.

Never collected

No password material

No credential harvesting, no destructive testing, no automatic changes to directory objects. Ever.
