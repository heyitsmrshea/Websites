Microsoft coverage

Exact domains, exact findings, exact limits.

Coverage depends on licensing and granted permissions. RoadRunner says what it can prove and what remains unknown.

Entra ID

Privileged roles, MFA coverage, Conditional Access gaps, risky users, legacy auth, guest exposure, and role drift.

Defender

Incident backlog, exposure signals, device risk, alert hygiene, and onboarding coverage where available.

Intune

Compliance policy coverage, unmanaged devices, stale enrollments, device encryption, and baseline gaps.

Exchange and M365

Legacy protocol exposure, mailbox forwarding, audit posture, sharing controls, and risky collaboration settings.

SharePoint and OneDrive

External sharing posture, sensitive site exposure, anonymous links, and admin control coverage.

Azure posture

Subscription security settings, Defender plan coverage, privileged access, network exposure, and policy gaps.

Sample Microsoft finding

Conditional Access excludes legacy service accounts without compensating control

HIGH
Affected4 accounts excluded from MFA policy; 2 observed interactive sign-ins in the last 14 days
EvidencePolicy exclusion list plus sign-in evidence shows recent use outside expected service context.
RiskExcluded accounts create a durable identity bypass that attackers can use after password compromise.
Recommended actionRemove interactive-capable accounts from exclusion or attach documented exception controls.
ValidationNext run must show no recent interactive sign-ins for excluded service accounts or an approved exception.
Closure ruleManual status cannot close this finding. Evidence from the next run must satisfy the validation condition.
