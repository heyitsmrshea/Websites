The finding

Policy exceptions are where tenants actually break.

A score will not tell you which four accounts bypass MFA. The finding does — and it names the condition that closes it.

Sample Microsoft finding · RR-F-0155

Legacy accounts bypass access policy

HIGH
Affected4 accounts excluded from MFA policy; 2 observed interactive sign-ins in the last 14 days
EvidencePolicy exclusion list plus sign-in evidence shows recent use outside expected service context.
RiskExcluded accounts create a durable identity bypass that attackers can use after password compromise.
Recommended actionRemove interactive-capable accounts from exclusion or attach documented exception controls.
ValidationNext run must show no recent interactive sign-ins for excluded service accounts or an approved exception.
Closure rule Manual status cannot close this finding. Evidence from the next run must satisfy the validation condition.
