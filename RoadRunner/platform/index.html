Source coverage

Signals are useful only when their limits are visible.

The live RoadRunner demo separates collecting sources, available connectors, blocked or limited sources, confidence, conflicts, and what each source unlocks. Missing visibility becomes work, not a quiet blank space.

Coverage stateWhat it saysAssessment value
CollectingThe source is fresh enough to create findings, verify closures, and show confidence level.Turns evidence into owner-ready work and gives closure a source-backed proof path.
Available to connectThe product knows the connector would improve coverage, but it is not currently connected.Creates an honest opportunity list: Action1 patch, CrowdStrike EDR, XDR hunting, or similar sources.
Blocked or limitedThe source is blocked by license, permission, export-only access, stale data, or unsupported API behavior.Prevents silent blind spots and explains exactly what would unlock better assessment.
ConflictTwo sources disagree or a source cannot fully support closure.Escalates ambiguity into a human decision instead of hiding it in a score.
Lifecycle

Discovery to closure without losing the thread.

The workflow is built for recurring execution, not one more static report.

01

Discover

Collect evidence, detect gaps, and baseline the tenant.

02

Qualify

Classify findings by state, confidence, conflict, source health, SLA, and owner.

03

Prioritize

Rank 72-hour, two-week, 30-day, backlog, blocked, waiting, regressed, and verified work.

04

Report

Show verified closure, regressions, blocked visibility, and source unlocks to leadership.
