Architecture

Simple enough to inspect. Strong enough to operate weekly.

RoadRunner is organized around the assessment chain: source evidence, stored proof, generated findings, assigned work, validation, and reporting.

Lifecycle

Discovery to closure without losing the thread.

The workflow is built for recurring execution, not one more static report.

01

Discover

Collect evidence, detect gaps, and baseline the tenant.

02

Prioritize

Rank findings across Microsoft, endpoint, cloud, and on-prem work.

03

Assign

Give owners the entities, fix steps, and validation criteria.

04

Report

Show verified closure, regressions, and blocked visibility to leadership.

Role-based views

Same evidence, different decisions.

RoadRunner should not make every stakeholder read the same security artifact.

MSP operator

Needs source health, client queues, owner status, blocked evidence, and service delivery notes.

Client executive

Needs risk direction, verified closures, unresolved priority items, and business-facing posture summaries.

Technical owner

Needs affected entities, fix steps, proof, and exact validation criteria for the next run.
