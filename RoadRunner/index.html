What RoadRunner does

It turns posture evidence into accountable weekly work.

Most tools expose more information than a lean team can absorb. RoadRunner turns the evidence into a smaller set of findings with owners, target states, and validation logic.

Evidence

Read Microsoft, endpoint, cloud, on-prem, and manual evidence sources without changing customer systems.

Findings

Produce findings that name affected entities and explain why the exposure matters.

Work queue

Rank fixes across domains so the team can decide what happens this week.

Closure trail

Stamp work closed only when the next run proves the evidence changed.

Sample assessment finding

Standing privileged access remains assigned outside emergency workflow

HIGH
Affected3 Global Admins, 2 Privileged Role Administrators
EvidenceEntra role assignments observed in current evidence snapshot; no just-in-time activation record attached.
RiskCompromised daily-use or stale privileged accounts can bypass normal access controls and expand blast radius.
Recommended actionMove standing admins to eligible access, require phishing-resistant MFA, and document break-glass exceptions.
ValidationNext run must show no standing privileged assignment except approved break-glass accounts.
Closure ruleManual status cannot close this finding. Evidence from the next run must satisfy the validation condition.
Weekly assessment loop

Six answers, in the same order every run.

The point is operational rhythm. A finding is not done because someone clicked done. It is done when source evidence proves it.

01

What changed

New, regressed, verified-closed, and data-gap findings this run versus last.

02

What matters

Ranked by exposure, exploitability, blast radius, and confidence in the evidence.

03

What to fix

A concrete target state, not vague guidance like review configuration.

04

Who is affected

Named accounts, devices, resources, groups, and paths. A count alone is not a finding.

05

How to fix it

Steps a capable IT generalist, MSP engineer, or security owner can execute or assign.

06

How to validate

Every fix states what next week's evidence must show before closure is stamped.
